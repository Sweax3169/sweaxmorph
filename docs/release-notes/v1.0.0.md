**Drop any file on Morph. Pick a format. Done.**

SweaxMorph 1.0 is a file converter for Windows 10 and 11 that lives one shortcut away.

- **Three ways in:** <kbd>Win</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd>, tap <kbd>Space</kbd> while dragging files in Explorer, or right-click → *Convert with SweaxMorph* (also in *Send to*).
- **126 formats, 229 extensions:** images (HEIC, AVIF, RAW, PSD…), video, audio, documents, spreadsheets, slides, PDF, e-books, data, archives, subtitles and fonts.
- **Shrink, Combine, three qualities**, results saved next to the original and never overwritten.
- **Offline.** FFmpeg, Pandoc and 7-Zip are downloaded once from their official releases the first time they are needed.

**Türkçe:** Dosyayı Morph'a bırak, formatı seç, bitti. Win + Alt + F, Gezgin'de sürüklerken Boşluk ya da sağ tık. 126 format, çevrimdışı.

### Download

- `SweaxMorph-win-x64.zip`: everything included. Unzip and run `SweaxMorph.exe`; it installs itself for your user (no admin).
- `SweaxMorph-lite.exe`: smaller, needs the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0).
