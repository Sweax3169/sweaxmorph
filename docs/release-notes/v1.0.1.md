**SweaxMorph 1.0.1**

- **LibreOffice conversions no longer hang.** PDF → Word and Apple Pages / Numbers / Keynote, Visio, Publisher files went through on the first try but waited forever on the second: LibreOffice, started headless on a profile it had used before, stopped at something it never showed. Every conversion now gets a fresh profile.
- **Lighter in the tray.** After start-up and after Morph hides, SweaxMorph hands memory back (about 5 MB working set while idle).

**Türkçe:** LibreOffice dönüşümleri (PDF → Word, Pages, Numbers, Keynote, Visio…) ikinci kullanımda artık takılmıyor; tepside beklerken bellek geri veriliyor.

### Download

- `SweaxMorph-win-x64.zip`: everything included. Unzip and run `SweaxMorph.exe`; it installs itself for your user (no admin) and replaces an older version.
- `SweaxMorph-lite.exe`: smaller, needs the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0).
