**SweaxMorph 1.0.3**

- **Morph rests even when it never got focus.** Windows sometimes opens Morph without giving it focus, for example while you are busy in another window. Morph then never "lost" focus, so its haze kept catching clicks meant for the windows below and it never dozed. Resting now follows focus on every frame.

Includes 1.0.2: Morph waits on top while you pick a file in Explorer (its haze fades so the windows under it can be clicked, and comes back as a drag heads its way), settings and close buttons on Morph's top-right, and Morph dozes when idle so leaving it open costs no CPU.

**Türkçe:** Windows bazen Morph'u odak vermeden açıyor (başka bir pencerede çalışırken). Bu durumda sis altındaki pencerelere gidecek tıklamaları yutmaya devam ediyordu; artık Morph odakta olmadığı her an bekleme moduna geçiyor. 1.0.2'deki her şey de içinde: dosya seçerken kapanmama, Ayarlar ve Kapat düğmeleri, boşta uyuklama.

### Download

- `SweaxMorph-win-x64.zip`: everything included. Unzip and run `SweaxMorph.exe`; it installs itself for your user (no admin) and replaces an older version.
- `SweaxMorph-lite.exe`: smaller, needs the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0).
