**SweaxMorph 1.0.4 — macro keys**

- **Shortcuts from macro keys.** Keys sent by macro software and keyboard drivers used to be ignored, so a macro key that pressed the shortcut did nothing. They count now; only SweaxMorph's own keys are skipped. Record a combination such as Ctrl + Alt + F9 on the macro key, then click *Change* in Settings and press the macro key.
- F13–F24, Pause, Scroll Lock and the launch keys can be the shortcut on their own.
- `SweaxMorph.exe --toggle` opens Morph, or puts it away, for macro apps and launchers that run programs.

**Türkçe:** Makro tuşları. Makro yazılımlarının ve klavye sürücülerinin gönderdiği tuşlar artık sayılıyor. Klavyendeki makro tuşuna Ctrl + Alt + F9 gibi bir birleşim kaydet, Ayarlar'da *Değiştir*'e basıp makro tuşuna bas. F13–F24, Pause ve Scroll Lock tek başına kısayol olabilir; program çalıştıran makrolar `SweaxMorph.exe --toggle` kullanabilir.

### Download

- `SweaxMorph-win-x64.zip`: everything included. Unzip and run `SweaxMorph.exe`; it installs itself for your user (no admin) and replaces an older version.
- `SweaxMorph-lite.exe`: smaller, needs the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0).
