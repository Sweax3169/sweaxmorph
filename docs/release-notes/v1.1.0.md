**SweaxMorph 1.1.0: quick, steady, and in eight flavours**

Morph looks and moves exactly as before, converts the same 103 test files, and is now measured, not guessed: the new
`--bench` mode timed 1.0.5 and 1.1 the same way on a Ryzen 5 7600 with a 240 Hz main monitor and two more.

| | 1.0.5 | 1.1 |
|---|---:|---:|
| Shortcut → Morph on screen, first time after start | 162 ms | **9 ms** |
| Shortcut → Morph on screen, later | 7 ms | 7 ms (it already was quick) |
| `--toggle` from a macro key or launcher, to open (median / worst) | 460 / 1,197 ms | **65 / 74 ms** |
| Two `--toggle`s 60 ms apart | 3 of 3 lost one | **none lost** |
| Shortcut while Morph waits on another monitor | hid it | **brings it over** |
| Layout passes per second while Morph moves | 240 | **0** |
| First open with a UI Automation client running | 222 ms | **9 ms** |
| Longest frame while a 4000 × 2600 photo converts | 97 ms | **24 ms** |
| Frame rate while opening / dragging | 233 / 238 per s | 233 / 231 per s (at the refresh rate) |
| Private memory after start | 73 MB | 87 MB (Morph is kept ready) |

### Fixed

- **"Sometimes it doesn't open."** Morph waits on top after you click elsewhere, and the shortcut then *hid* it, even on
  another monitor where you couldn't see it. Now the shortcut puts Morph away only when it is with you; otherwise Morph
  comes over. Space-while-dragging and the right-click menu bring it to the pointer as well.
- **"It doesn't open where I want."** Morph always opens on the pointer's monitor at that monitor's scale (it moves there
  first, then works out the spot), and a new setting chooses where: next to the pointer, the middle of the screen, or where
  you last dragged it.
- **Lag.** Morph was redrawn in a way that laid out the whole window every frame, which, with a UI Automation client
  around (touch keyboard, emoji panel, PowerToys), also walks and reports the whole window each frame. Now: a retained
  drawing, cached brushes, and a window that reports only itself.
- **Freezes and dead shortcuts.** 1.0 emptied its memory after every close, so the next open and the keyboard hook had to
  page it back in; Windows silently drops a hook that answers late once, and it was re-armed every 10 minutes. Memory now
  goes back only after 10 idle minutes, the hook allocates nothing and re-arms every 20 s, collections run in the
  background. Taking focus no longer borrows the input of a window that isn't answering. Result icons load off the UI
  thread.
- **`--toggle`** hands over before WPF starts, commands are never held back or merged, and the sender lets Morph take focus.
- **First open** is as quick as any: the window is built and drawn once at start, invisibly.

### New

- **Eight palettes** in Settings → Look: Candy (the original), Mint, Peach, Lagoon, Berry, Lemonade, Sunset, Cloud. Live
  tiles drawn by Morph itself; switching is instant, no restart.
- **Where Morph opens:** next to the pointer / middle of the screen / where I left it. Drag the cloud around Morph to move it.
- **Also over administrator windows** (opt-in): a tiny helper with administrator rights hears the shortcut in Task Manager,
  installers and many games. Windows asks once; SweaxMorph itself stays an ordinary app, so drag and drop keeps working.
- Morph stays on top of full-screen windows and raises itself once if another always-on-top window covers it.
- Settings from 1.0 carry over; the old file is kept as `settings.json.1.0.bak`.
- For developers: `--bench` (with `--uia`, `--dwm`) and `--palettes`.

**Türkçe:** Morph aynı görünüyor, aynı hareket ediyor, aynı 103 test dosyasını dönüştürüyor; artık tahminle değil
ölçümle hızlı. Kısayol, başka bir monitörde bekleyen Morph'u gizlemek yerine yanına getiriyor ("bazen açılmıyor"un
nedeni buydu). Morph her zaman imlecin monitöründe, o monitörün ölçeğinde açılıyor; Ayarlar'dan imlecin yanı / ekranın
ortası / bıraktığım yer seçilebiliyor (taşımak için buluttan sürükle). Her karedeki yerleşim turu kalktı (UI Automation
dinleyicisi varken bütün pencereyi dolaştırıyordu), ilk açılış 162 ms'den 9 ms'ye, `--toggle` 460 ms'den
65 ms'ye indi, art arda iki `--toggle` artık kaybolmuyor. Her kapanıştan sonra belleği boşaltıp klavye kancasını
yavaşlatan davranış ve yanıt vermeyen pencereye bağlanıp donma riski giderildi; kanca 20 saniyede bir yenileniyor.
Yeni: Ayarlar → Görünüm'de sekiz palet (Şeker, Nane, Şeftali, Lagün, Böğürtlen, Limonata, Gün batımı, Bulut), canlı
değişiyor; isteğe bağlı "Yönetici pencerelerinin üstünde de çalış" (Windows bir kez sorar). 1.0 ayarları korunuyor.

### Download

- `SweaxMorph-win-x64.zip`: everything included. Unzip and run `SweaxMorph.exe`; it installs itself for your user (no admin) and replaces an older version.
- `SweaxMorph-lite.exe`: smaller, needs the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0).
- `SHA256SUMS.txt`: checksums of both.
